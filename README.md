# Research

Working papers by Javier Blanco-Romero.

Work in progress. Not all claims have been verified by a human.

Each folder contains the manuscript in LaTeX and Markdown, references, figures, and supporting code where applicable.

| Paper | Scope |
| --- | --- |
| [Spacelike Guessing of Quantum Randomness](spacelike-quantum-randomness/index.md) | Bounds on guessing a vacuum-generated bit from a spacelike region. |
| [Boolean Oracles by Waiting](boolean-oracles-by-waiting/index.md) | A fixed two-body Hamiltonian implements Boolean oracles through its stopping time, with bounds on the required action. |
| [Identical Entropy Profiles, Different Prediction Costs](entropy-and-prediction-cost/index.md) | Stationary binary sources with the same entropy profiles can have sharply different prediction costs. |
| [On the Min-Entropy Asymptotics of Binary Context Graphs](binary-context-min-entropy/index.md) | Minimum mean cycles, algebraic noise-floor criteria, and finite-block certificates for binary sources. |
| [Soft-pair which-path records from a gapped detector](soft-pair-which-path-records/index.md) | A soft pair-emission channel records path information even when slow switching suppresses detector excitation. |
| [Two scales of nonclassicality near coherent states](near-coherent-nonclassicality/index.md) | Optical moments and Wigner negativity respond on different scales near coherent states. |
| [Causal-Exclusion Authentication in Quantum Field Theory](causal-exclusion-authentication/index.md) | Commuting local algebras turn a causal access restriction into a statistical authentication test. |
| [Modular Localization for Private Field Encodings](modular-field-encodings/index.md) | Coherent field encodings with explicit decoding error, leakage, and restricted preparation bounds. |

The research vision and original ideas are the author's. The author used OpenAI's GPT models, including Astra, and Anthropic's Claude Opus models for writing, theorem proving, and literature review. GPT models were used most often, and Astra was the most useful overall. This work is in progress. Not all claims have been verified by a human.
